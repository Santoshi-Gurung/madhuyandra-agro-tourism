
# Madhuyandra Agro Tourism (Booking and Management System)

Final Year Project | CS6P05NP | London Metropolitan University

## Aim
To develop a web-based system that helps Madhuyandra Agro Tourism promote its business, manage guests and bookings, and track payments.

## Objectives
1. Build a public website with packages, photos, map and reviews to attract guests.
2. Provide online booking with date selection, availability check and owner approval.
3. Enable advance payment through eSewa or Khalti (test mode) and record cash and bank payments.
4. Give the owner a dashboard and reports on bookings, guests and income.
5. Secure the system with login and separate guest and admin roles.

## Tech Stack
- Frontend: HTML, CSS, Bootstrap
- Backend: Python, Django
- Database: SQLite (development), PostgreSQL (final)
